# Homepage preview assets

The homepage illustrations are original SVG assets. The whale mark is reused from the project's
existing `icon.svg`; the banner and architecture diagram do not claim to be screenshots.

The two plugin previews are captured from the actual committed client bundle at
`b9f663c9e732e319a0920a3e02737400ee4cf0f2` in the existing isolated UI harness:

- `overview-dark.webp` — the dark overview page.
- `studio-light.webp` — the light Voice Studio page.

The preview uses fictional in-memory demo data and no trusted Host bridge (`bridge=none`). The
visible screenshot caption is an outer preview label, not a new feature added to the plugin.
These are layout previews, not evidence of real provider health, synthesis, preview, saving or
WeChat sending. Some demo controls and records illustrate capabilities that are not connected.

No real DSH desktop, chat/contact list, tokens, private audio, production configuration, audio device
or live backend is captured or contacted. The source client, styles and runtime functionality are
unchanged. Screenshots are exported as WebP for a compact README; they may be regenerated only
from an isolated fictional fixture environment and should be rechecked for privacy and accuracy.

Private desktop screenshots and runtime artifacts remain excluded from the repository. Only these
explicitly reviewed demonstration previews belong in this directory.
