# Plan 11 · TTS-D 云端与自定义 API Provider

**状态：PLANNED；前置：可扩展 Provider 契约与凭据安全模型。**

## 候选
Gemini TTS、OpenAI 语音 API、Azure Speech、ElevenLabs、自定义 HTTP/自托管 TTS。接入前逐个查证官方接口、现役模型、授权、费用及弃用时间；不可认为全都兼容同一协议。聊天 LLM 与语音 TTS 可自由组合。

## 安全设计
- 用户必须明确启用网络和可能收费的 Provider；默认绝不上传私人聊天文本/参考音频。
- API Key 由受保护的本机凭据存储处理，不进入 Git、公共 JSON、前端投影、查询字符串或日志。
- 自定义 HTTP 提供目标校验、重定向限制、私网/回环策略、DNS 重绑定防护、body/response 大小与时间限制、认证及错误脱敏，不能成为微信消息可控制的任意代理。
- 正确处理 Provider 支持语言/声音/克隆/情绪/流式/取消的差异；失败不自动切换付费服务。

## 验收
Fake Cloud 模拟错误 Key、限流、余额不足、5xx、非法音频、网络断连、超时、未授权访问，且不调用真实计费 API。真实试听必须另行授权。独立适配器 PR，通过后再启用。
