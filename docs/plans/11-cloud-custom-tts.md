# 11 · TTS-D：云端 Gemini/OpenAI/其他与自定义 API

**状态：PLANNED。** 前置：06/08；付费请求或真实凭据需要用户单独授权。

## 候选与原则

Gemini TTS、OpenAI 官方音频 API、Azure Speech、ElevenLabs、自托管 HTTP/自定义 Provider。重新核对实际可用模型、官方接口、价格、弃用/迁移与许可；不默认所有云端 API 为 OpenAI 兼容格式。

聊天 LLM 与 TTS 独立选择；DeepSeek 对话可以搭配任意已支持的 TTS。

## 安全设计

- API Key 存于受保护凭据环境，前端仅显示是否已配置；不可通过普通配置投影/URL/日志/仓库暴露。
- 云端文本/音频上传、费用/配额须显式授权与界面提示；不得因本地 Qwen 离线自动切换到计费 API。
- 自定义 URL 防 SSRF/DNS 重绑定/重定向/私网访问、超时、大小与格式限制，不能成为来自微信内容的任意 HTTP 代理。
- 不支持声音克隆/情绪等能力时，应显式禁用对应控件。

## 测试与交付

Fake Cloud 验证认证失败、429、额度不足、超时、5xx、音频损坏、拒绝重定向、未授权与取消、云端/本地状态隔离。每 Provider 单独 PR；真实付费联调另批准；完成停止。
