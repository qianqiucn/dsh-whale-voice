# 14 · Whale Voice 安装、轻量部署、社区音色与正式发布

**状态：PLANNED。** 必须等待 Provider、Relay、WeChatAgent、SVC 相关真实验收完成，不能因 UI/CI 绿就发布。

## 普通用户路径

1. 云端快速模式：无需独显或数 GB 模型，用户自己授权凭据与网络/计费。
2. 轻量本地模式：选经过核实可在 CPU 运行的模型；显示性能/体积。
3. 高性能本地模式：可自选 Qwen/IndexTTS/SVC，检测 GPU/内存，按需下载。
4. 所有模式依赖兼容的 WeChatAgent 才能使用微信能力；若缺失，可只用 TTS 试听/配置，不冒充微信已连接。

## 安装器/组件管理

DSH 检查、WeChatAgent 兼容表、Provider 模型依赖/下载来源/哈希、存储位置、自选安装/卸载、备份恢复与升级提示。不要自动覆盖私人声音或配置。禁止默认下载所有模型、要求关闭杀软或打包未经许可 DLL。

## 社区音色包

版本化 manifest、Provider 兼容、作者授权/许可、来源、hash/文件大小、沙箱导入与删除策略；第一版离线导入/导出，不自动上传私有参考音频。

## 验收矩阵

本地/云端/custom TTS、SVC、无 GPU、网络异常、授权失败、版本冲突、音频错误、发送 UNKNOWN、防重复发送、设备恢复、隐私/密钥、窗口与游戏模式、Windows 重装/升级/卸载、离线和服务退出。区分 OFFLINE / INTEGRATED / VERIFIED / RELEASE READY。

## 发布门禁

需要明确 Release/可见性/生产配置写入/真实微信发送和任何分发第三方组件的许可，逐项单独授权。提交用户文档、支持矩阵、安全/隐私与回退说明，完成后停止。
