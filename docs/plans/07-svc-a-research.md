# 07 · SVC-A：Seed-VC / RVC 唱歌引擎研究

**状态：PLANNED。** 前置：05 的 SVC 任务契约。

## 必须厘清

- Voice Conversion：已有歌声/人声输入，转换音色、尽量保留歌词/音高/节奏。
- Singing Synthesis：从歌词、音符或曲谱生成歌声，需要另一套生成引擎。
- 人声分离、后期混音是独立步骤；不要声称 Seed-VC 单独完成完整作曲。

## 研究任务

1. 静态核对 Seed-VC 官方及有维护的 Fork、模型/代码许可证、模型权重分发条件、Windows/Python/GPU要求；归档/维护风险须注明。
2. 核对 RVC 推理/模型格式、已有音色、训练前置、版本与许可证。
3. 比较零样本克隆、保留音高、中文歌/多语、长音频、资源、取消、误差、推理接口。
4. 设计纯人声→SVC→混音、整曲→分离→SVC→混音；允许跳过不必要步骤。
5. 处理素材版权、参考音色授权、临时文件隐私与上传风险；不能把第三方作者声音包自动打包发布。
6. 提出 SVC Provider Interface 与 Fake SVC 测试矩阵，包括音频超限、无伴奏、输出验证、强制取消和显存冲突。

## 交付

`docs/SVC_PROVIDER_RESEARCH.md`、候选能力/许可矩阵、硬件与版本说明、推荐 PoC 及独立 PR。无批准不下载大型模型、不执行来源不明程序、不生成或发送真实歌曲。完成停止。
