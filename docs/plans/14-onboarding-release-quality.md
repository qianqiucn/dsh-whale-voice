# Plan 14 · 一键安装、轻量部署与正式验收

**状态：PLANNED；前置：核心、至少一种受支持 Provider 和 Relay 发送方案完成可靠集成。**

## 最新已授权安装模式决策（2026-10-25；优先于旧默认项）

**Whale Singing 首次依赖弹窗默认推荐：RVC 标准翻唱。Seed-VC 只作为“后续可选 · 零样本免训练试唱”，不预装、不默认下载、不默认可用。** 两者使用同一个 Whale Audio Core，但按功能/模式生成互不强制的依赖清单。

- **RVC 主模式**：只列出被选中方案实际需要的 RVC Gateway、合法专属声线模型、条件 UVR/MSST/分离、混音/格式转换、宿主能力，逐项显示来源/许可/体积/资源状态；不要求额外安装 Seed-VC。
- **Seed-VC 可选模式**：在技术/授权/维护风险及 Windows 实测通过之前，仅以“免训练试唱（后续功能）”提示，不提供真实安装按钮、不触发下载；将来用户选择该模式时单独列 Seed-VC checkpoint、内容编码器、Vocoder、参考音频同意、资源与归档维护风险，复用已经验证的分离/混音依赖。
- **轻量术语约束**：“免训练/轻量上手”不等于“低显存、CPU 兼容、可实时唱歌”，任何 GPU/内存/时间要求必须有实测；Seed-VC 25M Tiny 不能冒充专用歌声方案的轻量代替品。真正无 GPU 的路径继续来自独立能力测试和可用服务选项，不假定 Seed-VC 解决。
- **负向验收**：首次 Singing RVC 模式不加载 Seed-VC；Voice TTS 首访不被 Singing 依赖阻塞；切换到 Seed-VC 时未验收模型禁用真实转换；未知模型许可、断线、CPU-only、CUDA 不兼容、显存不足、用户取消及重复进入不触发下载，已核验共用依赖不会重复安装。
- 原 Plan 14 的发布、隐私、安全、安装和生产权限门禁不变；文档调整没有安装或发布授权。

## 2026-10-25 · Voice/Singing 双首次使用安装与依赖供应链（原 Plan 14，仍 PLANNED）

**统一安装/组件中心，两张 feature-scoped 清单，禁止自动全量安装**。完整设计见 [Whale Audio Core 与双入口初始化规范](WHALE_AUDIO_CORE_AND_DUAL_UI_ONBOARDING.md)。
- 首次进入 **Whale Voice · 语音气泡**、**Whale Singing · 唱歌** 各弹一次所选模式下的“依赖检查与安装选项”对话框；保留已安装依赖的共享去重，安装与首次弹窗确认分离。后续用户换模型/版本不满足/主动点“管理依赖”时重查，但不得每次切页都强制弹窗。
- 清单必须区分共同 Core/Host、生成必需（择一 Provider）、条件人声分离/音频格式、投递专用 WeChatAgent/Relay/Voice Sender、可选模型与云端方式。普通语音无需安装大型唱歌模型；使用云端时不得强制本地 GPU；只看页面、试听既有 Artifact、保存不能被微信发送依赖阻断。
- Installer 未来需审定来源、许可、版本/签名/哈希、空间、Windows GPU/CUDA 与 CPU fallback、权限/费用、进度/取消/断点/失败恢复与清理、敏感数据范围、实际 Host 健康复验；不可把自动下载第三方 AGPL/许可不明整合包纳为默认安装。
- **Plan 09 先做仅 Fake 按钮/UI**，Plan 14/后续实施须针对每次真实安装、模型下载、配置写入和生产服务管理另获授权。已安装不等于已可用，已保存不等于运行时 APPLIED；现有 SetupWizard/ComponentsDialog 必须复用，不造第二个安装状态库。
- 验收分两入口：首访一次、跨入口独立提示、第二次不弹、共享依赖不重下、未联网/用户取消/权限拒绝/磁盘不足/错误版本/无 GPU/云端凭据缺失、可访问性/窄屏，以及完整卸载/升级后的状态纠正。没有真实 Host 证据不得标 VERIFIED。

## 2026-10-25 · RVC/SVC 翻唱可选安装与发布门禁（原 Plan 14）

翻唱组件可选，详细参见 [蓝图](RVC_SVC_COVER_INTEGRATION_BLUEPRINT.md)。AstrBot 插件及 RVCSVC-API 均不是 Whale Voice/鲸递默认必装依赖；普通用户可继续 CPU/云端 TTS 无 GPU 路线。
- 安装前显示合法来源的 RVC/SVC/分离软件和模型的版本、权利、独立进程、RAM/GPU/CUDA/磁盘及可停用选项。
- 复制/重分发前审计上游 AGPL-3.0 和 API 仓库未明确 LICENSE 的状态。未取得授权前不包含上游源码、整合包、私有权重或商用歌曲。
- 自动下载歌曲/模型、付费调用、真实微信交付、发布 Release 均是独立权限门禁；音频、Cookies、模型、个人音色、私人会话不能写进 Git/公开日志。
- 验收 CPU/noGPU、API 缺失、非法源、取消清理、隐私删除、离线试听、未经授权渠道、版本升级/回滚与 Windows 启动失败。真实硬件未测就不标 VERIFIED。

## 安装选择
- 云端 API 快速模式：无需本地大模型，但用户自行提供凭据并允许网络计费。
- 轻量离线 CPU 模式：选择有稳定 Windows 发行路径的轻量 TTS。
- 高性能本地模式：语音可选 Qwen/IndexTTS 等；唱歌首发选择 RVC，Seed-VC 仅在未来通过审核后以免训练试唱选配。依赖按需且在用户明确授权后下载，核对 GPU/许可证；AI 翻唱不是基本语音必装项。
- 用户可只预览或保存音频，不必在未授权时配置真实微信发送。

## 首次引导
检查 DSH、WeChatAgent、Whale Relay、目标权限、Provider 类型、模型依赖、隐私与 API 授权。显示安装体积、资源要求、失败恢复与撤销；绝不强制下载多个 GB 的 Qwen 权重。

## 模型与音色资产
受信任下载来源、哈希校验、安装/卸载/升级、版本兼容、可配置数据目录；社区音色包需要来源许可、同意、完整性和防止非授权声音克隆的数据规则。默认不上传私人参考音频。

## 最终测试
针对 CPU/no-GPU、GPU、本地/云端/自定义/唱歌、无网络、Provider 离线、未授权聊天、设备恢复、任务取消、UNKNOWN 去重、升级回滚、首次安装、秘密与私人数据、狭窄窗口布局和 Windows 兼容的 E2E 验收。OFFLINE/INTEGRATED/VERIFIED 分开，CI 绿色不等于真实发送验证。

## 发行门禁
公开仓库、发布 Release、打包第三方 DLL、支付 API、真实微信发送都需分别授权；许可与安全检查不通过不得发布。用户系统安全保护不能被要求关闭。
